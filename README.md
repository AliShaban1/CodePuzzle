# CodePuzzle

A simple code puzzle powered by ChatGPT, intended for educational purposes.

## Tech Stack

This project is built using the following technologies:

- **[Next.js](https://nextjs.org)**: A React framework that provides server-side rendering, static site generation, and a powerful routing system. It is used to build fast and scalable web applications.
- **[React](https://reactjs.org)**: A JavaScript library for building user interfaces. React's component-based architecture makes it easy to create reusable UI components.
- **[TypeScript](https://www.typescriptlang.org)**: A superset of JavaScript that adds static typing, making the codebase more robust and easier to maintain.
- **[PostCSS](https://postcss.org)**: A tool for transforming CSS with JavaScript plugins. It is used for tasks like autoprefixing, nesting, and other CSS optimizations.
- **[Vercel](https://vercel.com)**: A cloud platform for deploying Next.js applications. It provides features like automatic builds, previews, and global content delivery.
- **[Monaco Editor](https://microsoft.github.io/monaco-editor/)**: The code editor that powers Visual Studio Code, used in this project to provide an interactive coding experience with syntax highlighting and other advanced features.
- **[@dnd-kit](https://dndkit.com/)**: A modern drag-and-drop library for React, used to implement the drag-and-drop functionality for puzzle blocks.

## ChatGPT 4.1 Mini

This project leverages **ChatGPT 4.1 Mini**, a lightweight and efficient version of OpenAI's GPT-4 model, to enhance the user experience by providing intelligent feedback. ChatGPT 4.1 Mini is used to:

- Generate code given the user's prompt
- Provide full structure and explanation of each line of code

By integrating ChatGPT 4.1 Mini, the project ensures a more interactive and engaging experience for users, making it an excellent tool for educational purposes.

## Features

- Interactive code puzzles to enhance learning.
- Drag-and-drop functionality for sorting and arranging puzzle pieces.
- Real-time feedback and validation of solutions.
- Undo/Redo functionality for better user experience.
- Hint system to assist users in solving puzzles.
