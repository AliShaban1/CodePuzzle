# CodePuzzle

A simple code puzzle powered by ChatGPT, intended for educational purposes.

## Tech Stack

This project is built using the following technologies:

- [Next.js](https://nextjs.org) - A React framework for building web applications.
- [React](https://reactjs.org) - A JavaScript library for building user interfaces.
- [TypeScript](https://www.typescriptlang.org) - A strongly typed programming language that builds on JavaScript.
- [PostCSS](https://postcss.org) - A tool for transforming CSS with JavaScript.
- [Vercel](https://vercel.com) - Deployment platform for modern web applications.

## Features

- Interactive code puzzles to enhance learning.
- Drag-and-drop functionality for sorting and arranging puzzle pieces.
- Real-time feedback and validation of solutions.
- Undo/Redo functionality for better user experience.
- Hint system to assist users in solving puzzles.
